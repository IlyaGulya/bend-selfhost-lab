Read the verdict

One semantic boundary.
Two backends.

The front end decides what a program means. Shared lowering makes its execution explicit. Backends render that common program into C or JavaScript—not two independently evolving implementations of the language.

Keep meaning in FIR.

Checked front-end IR carries semantic and affine obligations across the boundary. Representation changes must preserve these obligations; a faster emitter is not permission to weaken them.

FIR_LAWS.md

Lower decisions once.

BIR is the shared place for executable structure, calls, captures, and value representation. Target emitters should not quietly invent different evaluation or ownership rules.

BIR_LAWS.md

Make data pay its way.

Use compact, scoped structures and explicit lifetimes. Count retained storage as well as work removed. Fewer scheduler operations alone did not guarantee a smaller process.

G24 R12 is a historical accepted checkpoint, not the latest experiment. Three same-host pairs on the full frozen compiler root produced these median durations. Both execution modes passed their recorded acceptance work.

Self-hosted means
it emitted itself.

The accepted record includes a native seed → JavaScript stage 1 → JavaScript stage 2 chain and a byte-identical JS compiler image. This is not pure-C self-hosting.

Full-root validation covered 12,456 checked definitions and 13,050 validated events, with no output patches or excluded checks. Runtime and AST checks support this checkpoint, not a universal semantic proof or a GPU/WASM claim.

A useful experiment can fail admission. These later diagnostics remain on separate branches; none earned a new compiler promotion. Each comparison keeps its own denominator and workload.

G79Projection leaves, without generic framesNOT ACCEPTED

A structural specialization bypassed generic scheduler bookkeeping for 255 eligible callees across 9,096 call sites. The counted registrations are not a count of heap allocations. This was an emitted-image diagnostic, not a promoted BIR transformation.

What held. Six selected-corpus full-work runs passed. Semantic checks exercised emitted Base, returns, captures, scheduler depth, and boundary negatives. The public boxed ABI stayed unchanged.

What did not. The memory gate required median C/N ≤ 1 and every pair ≤ 1.05. Both conditions failed. The CPU ratio’s 95% interval spans 0.505–1.648; two pairs do not establish a reliable speedup.

G77Measure the observer before trusting itDIAGNOSTIC

Paired observer-on/off runs and a native physical-memory sampler placed instrumented Node high-water rises after checking, around verification. That changed the next hypothesis—not the compiler’s acceptance status.

Heap-statistics calls can themselves allocate. GC callbacks did not cover every isolate or all pause time. No forced collection was used, and the data did not prove that the observer was perfectly passive or establish GC/JIT/OS causality.

A smaller loop.
Not a smaller standard.

The later screening loop uses a frozen source corpus and recorded work counts. It is smaller than the full compiler root; it is not a substitute for a full bootstrap or a license to compare different workloads as if they were equal.

Only promising candidates should pay the full self-hosting cost. Admission still requires behavior, work, memory, runtime, and byte-fixedpoint evidence at the appropriate gate.
