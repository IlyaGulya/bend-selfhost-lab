IR and lowering

IR is an internal program format. Lowering converts checked source data (FIR) into backend operations.

U32 is an unsigned 32-bit integer. F32 is a 32-bit floating-point value. Quantity records a binding’s use limit.

The arena stores syntax. An occurrence stores facts for one checking context. Several occurrences can refer to one term.

CheckedBinding stores quantity, type and type depth. It does not store a unique variable identity.

Symbol identifies a global declaration. TermVar.index selects a local environment entry.

Each operation produces one value. A Let block binds that value before the next block runs.

Project does not test the tag. LoadSymbol fixes the evaluation position. A nullary declaration runs again on each load.

Control: all 8 block variants

Source

Blocks form recursive trees. Region labels permit forward exits, not arbitrary jumps or loops.

Region(r,
  Branch(outer_ok,

      Return(1),

A failed test selects Region.next. A successful Return ends the code body. It does not execute Region.next.

Operands: all 10 Atom variants

Source

Arg{use, value} pairs an operand with a use limit.

Affine: at most one logical use. Many: repeated use is permitted.

Atom Meaning
Local{id} Read a value bound in this Code body.
Capture{slot} Read a positional value supplied by a closure.
Symbol{id, key} Refer to a public value by its canonical key. Strict reads use LoadSymbol.
Word{value} Hold a U32 integer.
Natural{value} Hold a natural-number constant. Native arithmetic has a size limit.
FloatBits{bits} Hold the 32-bit representation of an F32 value.
TextValue{value} Hold a string value.
Boolean{value} Hold true or false.
Null{} Hold a null placeholder, for example for a type-only reference. This is not Maybe.None.
Undefined{} Hold an undefined placeholder. This is not an unbound local.

Atoms contain no nested operation tree. Source Quantity also has Erased. Erased positions have no live Arg or Parameter.

Conversions

Numeric conversion and bit conversion are different operations. F32ToNat has target-dependent limits.

PrimU32ToNatU32 → Nat

Preserve the unsigned numeric value.

PrimU32FromNatNat → U32

Keep the low 32 bits; not a checked conversion.

PrimU32ToF32U32 → F32

Numeric conversion, rounded to binary32.

PrimF32ToU32F32 → U32

Truncate nonnegative values below 2^32. Invalid/range-exceeding values give zero. Fractions below one also give zero.

PrimF32ToNatF32 → Nat on valid input

JS uses Math.floor without range checks. C clamps negative values and checks the Nat limit. Invalid inputs do not have a common target contract.

Arrays

Indexes wrap modulo the nonempty array length. A returned pair is one tuple value.

PrimArrayNewNat,T → Array<T>

Allocate 2^depth elements initialized from the value. JS rejects depth > 31. C also includes the element-layout exponent in this bound.

Replace one wrapped-index element; return the array.

PrimArrayGetArray<T>,U32 → (Array<T>,T)

Read a wrapped-index element; return the array and value.

PrimArraySwapArray<T>,U32,T → (Array<T>,T)

Store the new element; return the array and old element. Not a two-index swap.

PrimArraySizeArray<T> → (Array<T>,U32)

Return the array and its element count, not its depth.

PrimArrayCloneArray<T> → (Array<T>,Array<T>)

Return original and copied array storage. This does not promise a recursive deep clone of element values.

PrimArrayAtomicOrArray<U32>,U32,U32 → (Array<U32>,U32)

Store bitwise old OR v.

PrimArrayAtomicXorArray<U32>,U32,U32 → (Array<U32>,U32)

Maps

Map operations use the native trie representation. A result pair is one tuple.

PrimMapBitString,Nat → (String,Bool)

Preserve the query and read one trie bit. A character occupies 33 positions: presence bit, then its 32 code bits from most to least significant. Past the end gives false.

PrimMapFindMap<&2,V>,String → Maybe<&2,V>

Follow each node's stored position; compare the complete key at a leaf. Return Some(stored value) or None. No map/query pair is returned. A hit shares the stored value; it does not deep-copy it. Node positions need not increase.

The catalog does not prove equal target support. F32ToNat has different target behavior for invalid inputs.
